# MiMo Mini Agent Demo

我实现了一个纯前端的 **MiMo Mini Agent Demo**，用于把用户输入的模糊目标快速转化为可执行的结构化方案。这个项目解决了“想法很多，但不知道怎么拆解成步骤”的痛点，适用于学习计划、任务管理、内容生成等场景。用户输入需求后，系统自动识别目标、拆解任务，并提供执行建议。整个项目完全基于浏览器，无需后端，适合公开展示和扩展。

## 使用方法

1. 在输入框中输入你的项目目标。
2. 选择工作模式和时间预算。
3. 点击“生成方案”按钮，即可看到结构化结果。
